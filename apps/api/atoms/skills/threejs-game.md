# Three.js 游戏制作指导

遵循模块化 Three.js 游戏工程组织，使用平台预装的 `three` 核心模块。将镜头、场景和输入放在职责清晰的模块中，HUD 读取真实规则状态。按玩法选择镜头和构图，保持屏幕方向、操控与空间反馈一致。用程序几何、材质、灯光或 CanvasTexture 建立可读的场景和地标。控制像素比与渲染开销，卸载时清理循环、监听和 WebGL 资源。

先把一段代表性流程接通，再扩展场景。可见地面、路线和障碍应与贴地、边界和碰撞共享几何依据。明确开局、暂停、重置与结算时哪些系统停止更新。实现奖励或进度标记时把触发条件、实际规则和 HUD 连起来。以本次玩法为准设计。
