# 网页分镜样片

此指导仅保留用于理解历史 HTML 分镜产物。新视频任务由 Vidu Q3 Pro 的原生文生视频 / 图生视频管线处理，不使用此 Skill 生成网页动画替代视频。

## 将脚本拆成镜头

- 根据用户要求确定片长、画幅、受众和表达目标。每段镜头明确起止时间、主体、画面变化和必要字幕。用清晰的开场、信息段和片尾组织视觉节奏。
- 用 HTML、CSS 或 Canvas 绘制实际画面。字幕保持可读，关键文字留在安全边距内。用一致的设计语言连接镜头。

## 播放与定位

- 用同一时间轴计算当前镜头和镜头内进度，让播放、暂停、拖动和重播调用同一渲染逻辑。优先用经过时间计算进度，处理结束和重新播放。
- 进度控件提供标签及当前时刻。暂停应停在当前画面，拖动应立即更新画面与字幕。摘要标明实际交付的是网页分镜样片。

## 交付前自检

检查播放和暂停，拖动跨越至少一个镜头边界，确认时刻、画面与字幕同步。播放到末尾后重播，验证第一段镜头从起点出现。
